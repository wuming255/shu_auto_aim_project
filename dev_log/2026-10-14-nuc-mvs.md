## 根因与头文件选择

- 原构建缓存为 `SRM_ENABLE_MVS=ON`、`SRM_MVS_INCLUDE_DIR-NOTFOUND`，直接 `--list-cameras --dry-run` 复现 unavailable；尚未调用 SDK。
- NUC 项目和当前用户目录没有参考头文件；从共享工作区已有 `sp_vision_25-main/io/hikrobot/include/` 复制七个原文件至 `/home/wuming/wuming/APP/mvs-reference-headers`。未下载 SDK。
- 从 NUC 已有 `APP/MVS-5.1.0_x86_64_20260909.tar.gz` 的嵌套 `MVS.tar.gz` 提取头文件与发布说明至 `APP/mvs-5.1-headers/`，只用于比较。发布说明确认其相机 SDK 为 4.8.2.2。
- `MvCameraControl.h`、`CameraParams.h`、`PixelType.h` 均不同，依用户优先级采用参考版。比较项目实际调用函数声明、USB/帧/像素转换/节点参数结构、尺寸/对齐/字段偏移及常量；NUC 4.7.0.3 包含全部调用符号。初始化/结束继续使用项目已有动态绑定，4.7.x 版本门未放宽。
- 发现参考版 `MV_CC_DEVICE_INFO` 为 572 字节，包中为 636 字节；USB 相关字段及 union 起始偏移相同。反汇编确认 NUC 4.7.0.3 的 USB CreateHandle 路径复制 `0x27c`（636）字节，因此原项目按旧结构复制再传回 SDK 会越界读取。
- 修复 `src/io/mvs_camera.cpp`：枚举结果持有枚举锁与 SDK 原生设备描述指针，用原指针完成 CreateHandle 后释放锁，避免截断描述及下次枚举导致失效。不推测/扩写 SDK 结构、不切换运行库。
- 两套头文件的 `MV_FRAME_OUT_INFO_EX=264`、`MV_FRAME_OUT=336`、像素转换结构 72 字节；项目读取的帧字段和转换字段偏移一致。4.7.0.3 GetImageBuffer 路径清零 `0x150`（336）字节，与参考版帧对象匹配。实际 BayerRG8 读取/转换通过；这些证据覆盖本项目当前 USB 使用路径，不等于认证 SDK 全部接口 ABI。
- 继续搜索 NUC 可读取的其他用户常见目录、`/opt/MVS`、系统 include 和现有 4.7 Runtime 包，未找到另一个配套的相机开发 include。

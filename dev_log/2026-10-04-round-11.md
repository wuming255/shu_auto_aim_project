# 第 11 轮开发日志：阶段七主循环与安全决策

日期：2026-10-04

## 本轮目标

完成阶段七的软件基础版本：在不接入真实相机、真实下位机、云台或发射机构的前提下，串联帧输入、阶段六算法管线和正式 USB CDC 传输，建立默认非开火的安全决策闭环。

## 开始前的复用检查

- 直接复用已有 `FrameSource`、`AutoAimPipeline`、`SelfAimTransport` 和正式协议编解码，不重复实现帧采集、PnP、跟踪、弹道或 CDC 帧布局。
- 参考项目只用于确认“输入→检测→跟踪→瞄准→通信”的主流程组织方式；其旧版 `SP` 帧头、CRC、四元数和命令字段未迁移。
- 安全门独立放在当前项目的 `SafetyController`，不把比赛正式协议之外的字段加入通信层。

## 实际完成

### 1. 安全决策控制器

新增：

- `src/control/safety_controller.hpp`
- `src/control/safety_controller.cpp`

实现：

- `safe`、`aiming`、`fire_ready` 三种决策状态；
- 传输未运行、设备断开、下位机状态缺失/过期、帧缺失/过期、处理失败、目标不可用、瞄准无效、弹速异常和视觉开火关闭等原因枚举；
- 同时检查阶段六瞄准结果中的 `bullet_speed` 和当前下位机状态中的 `bullet_speed`；
- 有效状态输出正式协议需要的角度制 yaw/pitch；无效状态回零；
- 默认 `allow_visual_fire=false`，默认和异常路径强制 `fire_flag=0`。

### 2. 运行时主循环

新增：

- `src/control/auto_aim_runtime.hpp`
- `src/control/auto_aim_runtime.cpp`

实现：

- `step()`：读取一帧、读取下位机状态、执行检测回调和 `AutoAimPipeline`，再写入安全命令；
- `run()`：启动/停止传输线程，处理文件输入 EOF 和外部停止请求；
- 检测异常和读帧失败时清理跟踪状态并进入安全命令；
- 安全决策时刻在 `FrameSource::read()` 之后重新采样，避免极快帧因时间采样顺序被判为未来帧；
- 退出前尝试同步发送一次 `fire_flag=0` 的安全帧。

### 3. 传输层安全补充

修改：

- `src/io/self_aim_transport.hpp/.cpp`
- `tests/self_aim_transport_test.cpp`

完成：

- 增加 `latest_state_timestamp()`，记录最近完整下位机状态帧的单调时间；
- 增加 `send_command_now()`，支持退出前同步发送确定的安全命令；
- 断链和重新打开设备时清除旧的下位机状态和状态时间戳，避免快速重连且尚未收到新状态时复用旧弹速；
- 保持正式 CDC 协议和默认非开火命令不变。

### 4. 自动化测试和构建

新增：

- `tests/safety_controller_test.cpp`
- `tests/auto_aim_runtime_test.cpp`

测试覆盖：

- 安全控制器有效瞄准、默认非开火和显式视觉开火门；
- 传输生命周期、状态缺失/过期、帧缺失/过期、处理失败、目标丢失、瞄准无效和弹速异常；
- Linux 伪终端模拟 CDC 下位机状态帧；
- 离线图片输入和合成检测结果进入阶段六 pipeline；
- 正式 18 字节命令中的 yaw/pitch 输出；
- 目标丢失和状态过期时安全回退；
- EOF/停止路径停止传输且不残留非零 `fire_flag`。

同时修正 `CMakeLists.txt` 中 `srm_transport` 与运行时库的 target 定义顺序，避免运行时库在依赖 target 创建前被当作普通链接参数。

## 本轮遇到的问题及处理

1. 运行时库原先在 `srm_transport` target 之前声明。已调整 CMake 声明顺序。
2. 运行时在读帧前获取决策时间，可能把刚生成的帧时间戳判断为未来时间。已改为读帧和处理后重新获取决策时间。
3. 安全控制器原先只依据 pipeline 中的弹速检查。已增加对当前下位机状态弹速的独立检查。
4. 退出时仅设置安全命令不能保证传输线程实际发送该命令。已增加同步发送接口并在运行时退出前调用。
5. 断链快速重连可能沿用旧状态。已在断链和重新打开设备时清理状态缓存和时间戳。

## 尚未解决的问题

- 当前运行时仍通过 `DetectionCallback` 注入检测结果，尚未提供绑定海康 MVS SDK 的专用 `FrameSource`；
- 阶段七只验证默认非开火和软件安全门，未验证真实下位机火控、人工许可、云台机械限位或发射行为；
- `SelfAimTransport` 仍是一次 `start()`/`stop()` 生命周期，同一实例停止后不能重新启动；
- 运行日志、配置文件加载和离线视频回放入口还需在阶段八整理；
- PnP 标定、云台方向、真实弹速、弹道偏置和空气阻力参数仍待最终现场验证。

# 第 1 轮开发日志：工程基础与正式协议

日期：2026-10-02

## 本轮目标

建立自瞄项目的长期开发基础，并在不大规模移植视觉业务的前提下，完成正式 USB CDC 自瞄协议的可编译、可测试实现。

## 实际完成

- 创建 `AGENTS.md`，记录项目目标、开发范围、规则/协议优先级、参考项目复用原则、文档和日志规范、开发流程、编译测试要求及必须询问的问题。
- 创建 `docs/` 并完成：
  - `requirements.md`
  - `architecture.md`
  - `protocol.md`
  - `development_workflow.md`
- 创建 `dev_log/`。
- 创建最小 CMake/C++17 工程，不依赖 OpenCV、OpenVINO 或相机 SDK。
- 实现 `src/protocol/self_aim_protocol.hpp/.cpp`：
  - 上位机 18 字节发送帧编码；
  - 下位机 30 字节接收帧解码；
  - 小端 `int16/int32/float32` 编解码；
  - 持久缓存和按 `body_len` 组帧的流式解析；
  - 非法长度、未知 ID 和不完整帧处理。
- 创建 `tests/self_aim_protocol_test.cpp`，覆盖：
  - 正常上位机帧编码；
  - 正常下位机帧解码；
  - 单字节拆包；
  - 多帧和剩余缓存；
  - 非法长度后的缓存丢弃；
  - 未知 ID；
  - 直接解码长度错误。
- 创建 `.gitignore`，忽略构建输出和临时文件。

## 验证命令与结果

执行：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j2
ctest --test-dir build --output-on-failure
./build/srm_protocol_test
```

结果：

- CMake 配置成功。
- C++17 协议库编译成功。
- 测试程序编译成功。
- CTest：`1/1` 测试通过，`100% tests passed`。
- 直接运行测试程序输出：`self-aim protocol tests passed`。

## 本轮遇到的问题及修复

1. 首次编译测试时遗漏 `<cstring>`，导致 `std::memcpy` 编译失败；已补充头文件。
2. 测试构造下位机帧时将 ID 2 写入了错误偏移，导致解码器报告记录 ID 错误；已按正式布局修正为：ID 2 位于偏移 24，弹丸速度位于偏移 26。

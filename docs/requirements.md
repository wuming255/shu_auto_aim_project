# 自瞄赛道需求

## 依据

- `shu_rules/rules.md`，当前工作区提供的校内赛规则。
- `shu_rules/self_aim_protocol.md`，当前工作区提供的正式自瞄通信协议。

## 任务目标

完成从目标检测、目标解算、云台瞄准到发射反馈的上位机闭环。靶标位于发射位约 5 m 处，为原地旋转的 140 × 125 mm 装甲板。

## 硬件与限制

- 相机：海康 CS016 工业相机；相机内参和外参由参赛者标定。
- 计算设备：现场提供的 x86_64 Linux NUC。
- 通信：USB CDC 虚拟串口，Linux 端通常为 `/dev/ttyACM*`。
- 弹丸：17 mm 小弹丸，由赛务提供。
- 每轮按 50 发计算；未发完仍以 50 发为分母，零发射本轮记 0。
- 不得修改下位机、发射机构、安全急停和机械限位。

## 功能需求

1. 稳定采集相机图像并提供时间戳。
2. 检测目标装甲板并获得可用于姿态解算的观测量。
3. 完成目标距离、方向和云台 yaw/pitch 计算。
4. 针对原地旋转目标进行跟踪和时间预测。
5. 根据下位机回传的云台状态和弹丸速度生成控制目标。
6. 通过正式协议持续发送完整的 yaw/pitch 和视觉开火请求。
7. 目标丢失、通信异常、解算无效或状态不可信时不得请求开火。
8. 记录日志、检测结果、状态和关键延迟，支持离线复现。

## 评分相关约束

命中率占自瞄赛道成绩 75%，因此优先保证稳定检测、预测正确和安全开火，不能用无约束高频开火换取表面效果。视觉 `fire_flag` 只是请求，真实发射还必须同时满足下位机火控和人工许可。

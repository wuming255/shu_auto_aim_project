# 开发与验证流程

## 轮次范围

每轮只完成一个可验证的垂直切片。轮次开始先检查规则、协议和参考项目中是否已有可复用实现，轮次结束必须更新 `dev_log/`。

## 标准命令

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j2
ctest --test-dir build --output-on-failure
```

## 验收要求

- 协议模块：单元测试通过，长度和字段布局与正式文档一致。
- 串口模块：先用伪终端或模拟字节流验证，再连接现场设备。
- 视觉模块：先用图片/视频离线验证，再打开真实相机。
- 发射模块：先验证非开火和断链保护，最后才在安全员许可下进行实弹测试。

## 日志要求

日志必须基于实际执行记录，包含：完成内容、命令和结果、问题、未解决事项、下一轮计划。不能把计划或预期结果写成已完成事实。
